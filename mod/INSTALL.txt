T2MPFix for Thief II multiplayer (NewDark 1.29) - four separate fixes
======================================================================

1. Smooth remote players (send_fix=1, recv_fix=1): other players' avatars are shown on their real
   path instead of lagging, sticking on geometry, floating or vanishing.
2. Stock steering bug (steer_fix=1): players without T2MPFix no longer drift several units behind.
3. 4-player cap (max_players=4): the 4th player joining no longer kicks two others.
4. Lava damage (damage_fix=1): lava and other local-only hazards hurt players again.

Each one has its own switch in T2MPFix.ini; set it to 0 to turn just that fix off. T2MPFix.log
lists which fixes are on.

Install (everyone in the session; a player without it is shown the stock way):

1. Install Thief 2 + NewDark 1.29 + the multiplayer beta. Easiest: T2Fix 1.29
   (https://github.com/Xanfre/T2Fix/releases, T2Fix_1.29-2026-09-16.exe), and tick
   "Thief 2 Multiplayer Beta" in the component list. Everyone must use the same version.
2. Copy dinput.dll and T2MPFix.ini from this folder into the game folder, next to Thief2MP.exe.
3. Start Thief2MP.exe. The game folder gets a T2MPFix.log; its first line should say
   "T2MPFix 0.1 on Thief2MP 1.29". If it doesn't appear, the exe is not the 1.29 MP exe.

Hosting and joining are unchanged (host port 5198, see the video guide).

Uninstall: delete dinput.dll and T2MPFix.ini. Single-player thief2.exe is not affected.
